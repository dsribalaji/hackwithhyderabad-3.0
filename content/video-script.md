# ShopMind — team video script (60–90 seconds)

Target length: ~80 seconds at a natural speaking pace (~200 words of voiceover).

---

## Shot 1 — opening (0:00–0:10)

**Visual:** Warm photo/illustration of a small provisions store; ShopMind title
card fades in: "ShopMind — the shopkeeper that never forgets."

**On-screen text:** *ShopMind — the shopkeeper that never forgets*

**Voiceover:** "Meet Lakshmi. Her provisions store runs on WhatsApp — and her
assistant never forgets a customer."

---

## Shot 2 — the problem, Day 1 (0:10–0:30)

**Visual:** Screen recording of the chat UI with the memory toggle set to OFF.
A message arrives: "Hi, do you have atta?" The reply is generic: "Yes! We have
5kg bags at Rs. 320. Would you like one?" Cut to the empty memory panel:
"Memories recalled: 0."

**On-screen text:** *Day 1 — Memory OFF: a polite stranger*

**Voiceover:** "On day one, the assistant is a stranger. Polite, generic — it
remembers nothing, so every customer starts from zero."

---

## Shot 3 — the payoff, Day 30 (0:30–0:55)

**Visual:** Same chat UI, memory toggle flipped to ON. The same question —
"Hi, do you have atta?" — and the reply: "Your usual 5kg bag, Lakshmi? A
fresh batch just arrived — and the mixer grinder you asked about on Day 15 is
back in stock." The side panel lights up, listing the recalled memories: her
name, her monthly order, her home-delivery preference, the grinder request.

**On-screen text:** *Day 30 — Memory ON: 5 memories recalled*

**Voiceover:** "Thirty days later, the same question gets a completely
different answer. It remembers her usual order, her delivery preference — and
the item she asked about three weeks ago. Same question. Same code. That's not
a chatbot. That's memory."

---

## Shot 4 — how it works (0:55–1:10)

**Visual:** The three-line agent loop on screen as clean code:

```
recall() → chat() → retain()
```

then a simple diagram: user message → Hindsight recall → reply → retained.

**On-screen text:** *recall → chat → retain — powered by Hindsight*

**Voiceover:** "Underneath, it's a tiny loop: recall relevant memories, answer
grounded in them, retain the exchange so the next turn is smarter. Memory is
powered by Hindsight, running fully self-hosted — no cloud, no signup."

---

## Shot 5 — closing (1:10–1:25)

**Visual:** Back to the store image. Final card: "ShopMind — memory is the
assistant." Repo link on screen.

**On-screen text:** *ShopMind — memory isn't a feature. It is the assistant.*

**Voiceover:** "Small shops lose customers by forgetting them. Ours never
does."
