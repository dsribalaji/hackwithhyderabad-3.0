# ShopMind — social posts (LinkedIn / X)

## Variant 1 — the before/after hook

Same question. Same assistant. Two completely different answers.

Memory OFF: "Yes! We have 5kg bags at Rs. 320. Would you like one?"
Memory ON: "Your usual 5kg bag, Lakshmi? And the mixer grinder you asked about on Day 15 is back in stock."

We built ShopMind — a shop assistant for small retailers that remembers every customer. Powered by Hindsight (Vectorize's agent memory), fully self-hosted, zero signup to run the demo.

The memory layer is visible, not a black box: every reply shows exactly which memories it recalled.

## Variant 2 — the "shopkeeper that never forgets" hook

Meet Lakshmi. She runs a provisions store on WhatsApp.

Day 1, her assistant is a stranger: polite, generic, forgets everything.
Day 30, it's the shopkeeper with ten years of relationships: "Your usual 5kg atta? The grinder you asked about is back — want me to set one aside with home delivery?"

That's ShopMind — our memory-powered assistant for small retailers, built on Hindsight. The whole learning curve is three lines of agent logic: recall → chat → retain.

Small shops lose customers by forgetting them. Ours never does.

## Variant 3 — the builder hook

I wanted to see what an agent looks like when memory is the product, not a feature.

So we built ShopMind: every exchange retained, every reply grounded in recalled history. Flip one toggle and the same question goes from generic price quote to a personalized answer built from 30 days of customer memory — with the recalled memories listed on screen.

Self-hosted Hindsight, local embeddings, no cloud signup. The demo story: one customer, one 5kg bag of atta a month, and a mixer grinder she asked about three weeks ago.

Honest note: the 30 days are pre-seeded, not learned live — the demo proves recall. The live retain-then-recall turn is what proves learning, and it's the first thing we show when asked.

Repo: https://github.com/dsribalaji/hackwithhyderabad-3.0
